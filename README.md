# Business Summary Dashboard

## Project Description
This project presents a Business Summary Dashboard developed using Tableau Public. It helps visualize and analyse business sales data.

## Dashboard Features
- Business Summary
- Sales by Country
- Sales by Sales Person
- Amount
- Boxes Shipped
- Count of Data

## Tools Used
- Tableau Public
- Data Visualization
- Data Analysis
